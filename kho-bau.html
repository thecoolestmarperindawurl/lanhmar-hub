DÙNG NHANH

Ba bước để có recap

1

Cài một lần

Cần Python và ffmpeg, rồi cài thư viện theo file requirements trong repo.

2

Dán link Drive

Dán link Drive. Link công khai chạy ngay; file chia sẻ theo email thì đăng nhập Google một lần (chỉ đọc Drive). Hoặc đưa đường dẫn file trên máy.

3

Mở recap.html

Mỗi slide kèm lời giảng ở đúng slide đó. Dừng giữa chừng được, chạy lại là làm tiếp.

python recap.py "https://drive.google.com/file/d/<ID>/view" --title "Buổi 1"

Hướng dẫn đầy đủ, tuỳ chọn và giới hạn nằm trong README của repo.

★ BẢN ĐẦY ĐỦ

Muốn dùng bản mình đang dùng?

Bản mình dùng cá nhân có thêm bước nối Claude API, giúp recap sát bài giảng hơn:

  • Làm sạch lời giảng theo ngữ cảnh, sửa thuật ngữ và tên riêng bằng cách đọc cả ảnh slide
  • Viết ghi chú theo chủ đề: phần, mục, hộp ghi nhớ, ảnh slide, phần tổng kết
  • Tự bỏ phần giới thiệu và nội quy, chỉ giữ kiến thức và bài tập thực hành

Bản này nằm trong Data Storage. Để mở truy cập, mình rất mong nhận một khoản ủng hộ nhỏ (số tiền tuỳ tâm). Bạn đăng ký, nhận mã QR chuyển khoản riêng, mình duyệt thủ công rồi bạn vào xem.

Bản này cần API key Claude của riêng bạn và bạn tự chịu chi phí API.
