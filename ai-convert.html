File → Markdown cho AI

Thả PDF, Word, Excel, PowerPoint, HTML hay file code vào đây. Mình chuyển hết sang Markdown sạch để Claude, ChatGPT, Cursor… đọc nhanh hơn, hiểu cấu trúc tốt hơn và tốn ít token hơn. File được xử lý ngay trong trình duyệt của bạn, không tải lên máy chủ nào.

Kết quả

Dùng trong vibe code thế nào?

  1. Bỏ vào repo: giải nén .zip vào thư mục docs/context/. Trong CLAUDE.md (hoặc .cursorrules) ghi một dòng: “Tài liệu tham khảo nằm ở docs/context/, đọc INDEX.md trước.” Agent sẽ chỉ mở đúng file cần, thay vì nhai cả PDF.
  2. Dán thẳng vào chat: dùng “Copy tất cả” hoặc file context.md. Mỗi tài liệu được bọc trong thẻ <document> để AI phân biệt nguồn.
  3. Tài liệu dài: bật “Chia đoạn” để mỗi phần vừa cửa sổ ngữ cảnh, đưa lần lượt từng phần.
  4. Ảnh, sơ đồ, bản scan: công cụ này chỉ lấy chữ. Với ảnh, gửi thẳng ảnh cho AI (các model hiện nay đọc được ảnh) sẽ chính xác hơn.

Ước tính token là con số thô (≈ số ký tự ÷ 4 với tiếng Anh, ÷ 3 với tiếng Việt có dấu), chỉ để so sánh. Số thật phụ thuộc tokenizer của từng model.
